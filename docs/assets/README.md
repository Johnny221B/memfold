# README figures

Figures are reproduced from the authors' supplied paper artwork and the [MemFold project page](https://memfold.github.io/). The original bytes are preserved; no curves, labels, scores, or response text were redrawn or changed. `provenance.json` records the source and SHA-256 of each file.

| Asset | Content |
|---|---|
| `memfold-logo.png` | Project mark supplied with the paper figures |
| `method.png` | On-policy rollout, teacher scoring, and policy optimization |
| `training-efficiency.png` | Qwen2.5-3B training curves: updates and student rollouts |
| `memory-analysis.png` | Qwen3-4B budget, cost, and memory-intervention analysis |
| `personalization-case.svg` | Website's reflow of the PrefEval example |

The README's numerical tables are transcribed from the project website's `script.js` on 2026-09-29. Its figure comparisons and checkpoint protocols must not be conflated with new benchmark runs. These files are documentation assets; they do not add training datasets or generated evaluation corpora to the code repository.
